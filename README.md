## This is me :)

Hi, I'm **Shreyansh**, a Computer Science undergrad and full-stack developer, broadcasting from Rajasthan, India 🇮🇳. 
I build scalable web applications, explore system architecture, and I'm a little obsessed with blending AI into practical solutions.

- 🤖 Unapologetically obsessed with **Linux, NLP, and System Administration**. From configuring AWS/EC2 servers to setting up Nginx and Apache.
